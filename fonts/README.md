# ITC Cheltenham Condensed

Drop the licensed font files here with these exact names and the site picks them up with no code change:

- cheltenham-cond-bold.otf      (Bold — headers)
- cheltenham-cond-bold-italic.otf
- cheltenham-cond-book.otf      (Book/Regular — body)
- cheltenham-cond-book-italic.otf

Files are the Std Condensed .otf set (installed 2026-10-21).
Until the files exist the browser falls back to EB Garamond.
